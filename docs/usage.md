# 사용 안내

## 열기와 탐색

**⌘O**에서 이미지·PDF·폴더·압축파일을 함께 선택할 수 있습니다. 파일을 이미지 영역·목록·도구 모음에 끌어놓아도 열립니다.

파일 하나를 열면 기본적으로 그 파일만 표시합니다. 같은 폴더의 이미지도 함께 보려면 **같은 폴더 열기**를 사용하거나 환경설정에서 해당 옵션을 켭니다. 목록 검색은 **⌘F**, 이전·다음 탐색은 **← / →**입니다. 목록의 순서와 현재 선택은 이미지 이동에 맞춰 갱신됩니다.

목록에서는 **⌘ 클릭**으로 여러 항목을 고르고 **⇧ 클릭**으로 범위를 선택합니다. 여러 이미지를 선택한 뒤 우클릭하거나 **⌘T**를 누르면 선택 메뉴가 열립니다.

## 화면 구성과 보기 효과

- **1 / 0 / 8**: 화면 맞춤 / 원본 크기 / 폭 맞춤
- **+ / −**, 핀치: 확대·축소
- 확대 상태에서 드래그·트랙패드 스크롤: 이미지 영역 이동
- **⌘R / ⌘L**: 오른쪽·왼쪽 회전
- **7 / 6**: 두 장 보기 / 읽기 방향 전환
- **Tab / Esc**: 이미지 영역에서 집중 보기 / 복귀

도구 모음과 목록·정보 패널은 각각 숨길 수 있습니다. 화면 구성을 되돌리려면 **보기 → 기본 화면으로 복원**을 사용합니다.

우클릭의 **이미지 필터**에서 부드럽게·선명하게·부드럽게+선명하게를 선택합니다. 선택한 필터는 다른 이미지와 재실행에도 적용됩니다. **환경설정 → 일반**에서는 다크·라이트·시스템 테마를 고를 수 있습니다.

## 책갈피와 슬라이드쇼

**B**로 현재 위치에 책갈피를 추가하고 상단 책갈피 버튼 또는 **F3**으로 목록을 엽니다. 책갈피에는 이미지와 페이지 위치가 저장됩니다. 성공적으로 연 책갈피를 자동 삭제할지는 환경설정에서 선택합니다.

슬라이드쇼 버튼을 누르고 간격을 선택하면 바로 시작합니다. 마지막에서 반복하기와 무작위 순서도 메뉴에서 설정할 수 있습니다. PDF에서는 페이지를 넘깁니다.

## PDF 보기와 묶기

PDF 하단에는 파일명과 페이지 입력·이전·다음 버튼을 한 줄로 표시합니다. 페이지 번호를 입력하고 Return 키로 이동하거나 방향키로 넘길 수 있습니다.

이미지를 여러 장 선택하고 **선택한 이미지로 PDF 만들기…**를 선택합니다. 페이지 목록을 끌어놓거나 위로·아래로 버튼을 눌러 순서를 바꿉니다. **추가 출력 설정**에서 용지와 페이지 여백을 정할 수 있습니다.

PDF를 이미지로 다시 저장하면 렌더링된 현재 페이지를 사용합니다. PDF의 벡터와 텍스트는 유지하지 않습니다. 암호로 보호된 PDF는 먼저 암호를 해제해야 합니다.

## 이미지 변환과 투명 여백

**⌘T**로 변환창을 엽니다. 기본 화면에서 저장 위치와 출력 형식을 고릅니다. 하단의 **추가 출력 설정**을 펼치면 크기·종횡비·압축 품질·여백·배경색·현재 보기 효과를 조절할 수 있습니다. 설정을 접어도 값은 유지됩니다.

PNG·WebP·TIFF·PDF는 투명·반투명 여백을 지원합니다. JPEG·BMP는 선택한 배경색으로 합성합니다. PDF의 투명 여백은 일반 뷰어에서 흰 용지처럼 보일 수 있습니다.

애니메이션과 여러 페이지 파일은 현재 프레임·페이지를 저장합니다. 목록에서 현재 열지 않은 파일을 선택했다면 첫 프레임·페이지를 사용합니다. 원본 EXIF는 출력 파일에 복사하지 않습니다.

## 흰 배경 제거

**도구 → 흰 배경 제거하여 저장…** 또는 이미지 우클릭 메뉴를 선택합니다. 저장 위치와 형식을 고른 뒤 전후 미리보기를 확인합니다.

| 옵션 | 동작 |
| --- | --- |
| 가장자리와 이어진 영역 | 테두리에서 연결된 흰색을 제거하고 닫힌 영역 안의 흰색을 보존 |
| 이미지의 모든 흰색 | 피사체 안의 흰색까지 제거 |
| 허용 범위 | 값이 클수록 흰색에서 더 멀리 떨어진 밝은 색도 제거 |
| 가장자리 부드럽게 | 반투명 경계와 흰 테두리를 보정 |

미리보기는 축소본이며 저장은 원본 해상도로 처리합니다. 기본 출력은 `원래이름-transparent.png`입니다. 원본이나 그 원본을 가리키는 링크에는 저장할 수 없습니다. 저장 취소·실패 시 기존 대상 파일도 보존합니다.

색상과 연결 영역을 이용하므로, 배경과 이어진 흰 피사체도 제거될 수 있습니다. 허용 범위를 낮추거나 제거 범위를 바꾸면서 확인하세요.

## 설정과 단축키

환경설정은 **일반 / 성능 / 단축키**로 구성합니다. 메모리와 기기 사양을 보고 캐시 프리셋을 고를 수 있습니다. 캐시 예산은 앱 전체 메모리 사용량의 상한이 아닙니다.

단축키는 검색해서 변경·비우기·복원할 수 있습니다. 중복된 키는 저장 전에 표시하며 메뉴·도움말에도 변경 내용을 반영합니다.
